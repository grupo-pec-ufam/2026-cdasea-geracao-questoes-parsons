# Conjunto de rótulos (labels)

Rótulos padronizados para as issues dos projetos. Use o script `criar-labels.sh` para criá-los automaticamente, ou crie manualmente em cada repositório (Issues > Labels) copiando nome, cor e descrição.

## Tipo de tarefa

| Nome | Cor | Descrição |
|------|-----|-----------|
| `tarefa` | `#1d76db` | Tarefa geral do projeto |
| `experimento` | `#8250df` | Rodar/analisar um experimento |
| `dados` | `#0e8a16` | Coleta, limpeza ou tratamento de dados |
| `leitura` | `#5319e7` | Ler artigo, tomar notas, revisar literatura |
| `escrita` | `#fbca04` | Redação de texto (relatório, artigo, resumo) |
| `código` | `#006b75` | Desenvolvimento ou refatoração de código |
| `bug` | `#d73a4a` | Algo que não está funcionando |
| `dúvida` | `#d876e3` | Pergunta a esclarecer |

## Prioridade
